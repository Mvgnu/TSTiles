Legende

Was Sie bekommen

  • 01Kostenlos

    Keine Rechnung, kein Abo, kein Kontingent. Die einzige Bedingung: der sichtbare Link auf itstiles.com in der Kartenzuschreibung.

  • 02Kein Login, kein API-Key

    Keine Registrierung und keine Schlüssel im Quellcode. Eine öffentliche URL genügt.

  • 03Die ganze Welt, z0–15

    Vektorkacheln für den gesamten Planeten aus OpenStreetMap-Daten (Protomaps-Basemap), bis Zoomstufe 15 und darüber scharf vergrößert.

  • 04DSGVO-freundlich

    Keine Cookies, kein Tracking, keine Analytics. Schriften und Symbole liefert itstiles.com selbst. Server in Frankfurt am Main, ausgeliefert über Cloudflare.

HTML · jede Website

Ohne Build-Schritt. Fehler erscheinen direkt in der Karte.

<link rel="stylesheet" href="https://itstiles.com/assets/maplibre-gl.css">
<div id="karte" style="height:420px"></div>
<script type="module">
  import { createMapViewer } from "https://itstiles.com/assets/embed.js";
  createMapViewer({
    container: "karte",
    manifestUrl: "https://itstiles.com/maps/light.json",
    center: [9.0576, 48.5216], // [Länge, Breite]: Tübingen
    zoom: 13,
    cooperativeGestures: true,
  }).catch((error) => console.error(error));
</script>

npm · React, Next.js, Vite

Mit eigenem MapLibre. In React im useEffect erstellen und mit map.remove() aufräumen.

// npm i -E maplibre-gl@5.24.0 pmtiles@4.3.0
import maplibregl from "maplibre-gl";
import { Protocol } from "pmtiles";
import "maplibre-gl/dist/maplibre-gl.css";

maplibregl.addProtocol("pmtiles", new Protocol().tile); // einmal pro Seite

export const map = new maplibregl.Map({
  container: "karte", // braucht eine Höhe, z. B. 420px
  style: "https://itstiles.com/styles/protomaps/light.json",
  center: [9.0576, 48.5216], // [Länge, Breite]: Tübingen
  zoom: 13,
  cooperativeGestures: true,
});

Die eine Bedingung: Lassen Sie die Kartenzuschreibung sichtbar. Sie enthält automatisch den Link auf itstiles.com sowie Protomaps und OpenStreetMap. Details in den Nutzungsbedingungen.
